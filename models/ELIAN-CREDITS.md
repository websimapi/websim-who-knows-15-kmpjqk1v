# Dr. Elian Frost / White
The appearance is an interpretation of npc/white/soul.md: practical ivory clothing, spectacles and short graying hair for a traveling rural physician. The missing medical bag is deliberately absent.
Head geometry derives from MakeHuman community bundled base.obj and male young/old macro targets, licensed CC0 1.0. See https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md and LICENSE.ASSETS.md. MakeHuman application code has a separate AGPL license; no application code is embedded in the model.
Skin atlas, spectacles, groom and clothing adaptation created for this project. The character reuses the game's existing X Bot rig and animation clips; their provenance is unchanged.
Seven game clips, bilateral BlinkLeft/BlinkRight morphs, and 24 two-segment hair guides. Runtime hair is an approximation with pinned roots, gravity and collision, not a full strand simulation.
