# Sera Moss / Green
Appearance interprets npc/green/soul.md: council surveyor, moss wool, linen shirt, field map, rule, pencil and compass. The map does not establish round evidence. Hair length was requested by the user.
Anatomy derived from MakeHuman bundled CC0 base and female macro targets, customized from the project's Leonie mesh. See https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md and LICENSE.ASSETS.md. Application code is separately AGPL; no MakeHuman application code is embedded.
Clothing, skin adaptation, survey tools and groom authored for this game. Existing X Bot rig and clips reused with unchanged provenance.
Hair: 3600 tapered fibers, 32 filled locks, 32 twelve-segment guides, pinned roots, gravity, damped inertia, aerodynamic wind drag, compliant length constraints, local bending, body ellipsoids and arm capsules. This is a real-time approximation; not individual-strand salon simulation. Bilateral blink morphs and seven game clips.

Physics revision: informed by this user-owned Hair Salon source (project evgsrv7yf3u8i5krs6zv, version 4) and Macklin et al., XPBD, https://matthias-research.github.io/pages/publications/XPBD.pdf. The scene uses actual strand geometry driven by simulation guides; it is not a full individual-strand salon solver.
